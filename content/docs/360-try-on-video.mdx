# 360° Try-On Video Guide

VFitly supports 360° try-on videos for users who want a richer preview than a still image. Video generation is best used after you have found a strong still-image result.

## When to use 360° video

Use it when you need:

- a more dynamic product presentation;
- a richer preview for social or marketing content;
- a stronger visual comparison before purchase;
- a polished output for a final candidate outfit.

For quick exploration, start with [AI Clothes Changer](/dashboard/try-on) still images first.

## Recommended workflow

1. Generate a still try-on image in [AI Clothes Changer](/dashboard/try-on) or [Product Try-On](/dashboard/product-try-on).
2. Review the output in [History](/dashboard/history).
3. Choose only the strongest candidate.
4. Generate a 360° try-on video if the interface option is available.
5. Save or revisit the final result from [History](/dashboard/history).

## Usage limits

360° video generation requires more processing than still images, so plans include specific video allowances:

- Free: 1 free 360° try-on video per account.
- Plus: monthly 360° video allowance.
- Ultra: higher monthly 360° video allowance.

Check the current allowances on [Pricing](/pricing).

## Tips for better outputs

- Use a clean person image.
- Avoid heavily cropped source images.
- Start with a still image and only convert strong results into video.
- Keep reusable clothing assets in [Wardrobe](/dashboard/wardrobe).
