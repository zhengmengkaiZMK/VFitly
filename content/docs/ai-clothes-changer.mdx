# AI Clothes Changer Guide

[AI Clothes Changer](/dashboard/try-on) is the core VFitly workflow. It helps you preview how a clothing item may look on a person photo.

## When to use it

Use this feature when you have:

- a person photo;
- a clothing product image;
- a style reference you want to test;
- multiple outfit ideas to compare.

If your starting point is a shopping URL instead of an image, use [Product Try-On](/dashboard/product-try-on).

## Step-by-step workflow

1. Open [AI Clothes Changer](/dashboard/try-on).
2. Upload a clear person image.
3. Upload or select a clothing image.
4. Confirm the generation settings available in the interface.
5. Generate the try-on preview.
6. Review the result in [History](/dashboard/history).
7. Save reusable clothing assets in [Wardrobe](/dashboard/wardrobe).

## Image recommendations

For best results:

- use a clear, well-lit person photo;
- avoid heavy blur, extreme poses, or large obstructions;
- use clothing images where the item is visible and not overly cropped;
- test still images first before creating a 360° video.

## Common use cases

- Compare two similar jackets before buying.
- Test whether a dress style fits your visual direction.
- Create fashion content concepts for social media.
- Preview catalog items on a consistent model photo.
