# VFitly Documentation

VFitly is an AI virtual try-on workspace for shoppers, creators, and fashion teams. You can preview clothing on a person photo, try products from shopping links, save reusable items in a virtual wardrobe, and review generated results in history.

## Core workflows

### 1. AI Clothes Changer

Use [AI Clothes Changer](/dashboard/try-on) when you already have a person photo and a clothing image. This is the fastest way to test a top, dress, jacket, or outfit idea before buying or publishing.

Read the full guide: [AI Clothes Changer Guide](/docs/ai-clothes-changer)

### 2. Product Try-On

Use [Product Try-On](/dashboard/product-try-on) when you found an item on Amazon, eBay, Temu, Shopify, SHEIN, or another shopping page. Paste a product URL, extract the product image when available, then move into virtual try-on.

Read the full guide: [Product Try-On From Shopping Links](/docs/product-try-on)

### 3. Virtual Wardrobe

Use [Wardrobe](/dashboard/wardrobe) to keep reusable clothing assets in one place. It helps you compare looks faster and avoid uploading the same item repeatedly.

Read the full guide: [Virtual Wardrobe Guide](/docs/virtual-wardrobe)

### 4. 360° Try-On Videos

Use 360° video generation when a still image is not enough and you want a richer, more dynamic preview. Free accounts include one video per account, while paid plans include monthly allowances.

Read the full guide: [360° Try-On Video Guide](/docs/360-try-on-video)

### 5. History and result management

Use [History](/dashboard/history) to review completed generations, compare previous outputs, and return to useful results.

Read the full guide: [History and Results Guide](/docs/history-results)

### 6. Credits and plans

VFitly uses credits for try-on generation. Paid plans include more monthly credits and 360° video allowances. View current plan details on [Pricing](/pricing).

Read the full guide: [Credits and Plans](/docs/credits-and-plans)

## Recommended first session

1. Create an account or sign in from [Login](/login).
2. Open the [Dashboard](/dashboard).
3. Upload a clear person photo in [AI Clothes Changer](/dashboard/try-on).
4. Try one clothing item or use [Product Try-On](/dashboard/product-try-on) for a shopping link.
5. Save useful items to [Wardrobe](/dashboard/wardrobe).
6. Review outputs in [History](/dashboard/history).

For the shortest path, start with the [Quick Start](/docs/quick-start) guide.
