# Virtual Wardrobe Guide

[Wardrobe](/dashboard/wardrobe) helps you keep reusable clothing assets organized. It is useful when you want to test the same item across different photos or build a library of fashion ideas.

## Why use Wardrobe

A virtual wardrobe helps you:

- avoid uploading the same clothing image repeatedly;
- keep strong product candidates in one place;
- build a reusable item library for future try-on sessions;
- compare different outfit ideas over time.

## How to use it

1. Generate a result from [AI Clothes Changer](/dashboard/try-on) or [Product Try-On](/dashboard/product-try-on).
2. Save useful clothing items to [Wardrobe](/dashboard/wardrobe).
3. Reuse saved items in future try-on sessions.
4. Remove outdated or low-quality assets when they are no longer needed.

## Free and paid usage

Free accounts may have limited wardrobe capacity. Paid plans include more generous usage and unlimited wardrobe capacity depending on the current plan. See [Pricing](/pricing) for details.

## Tips for organization

- Keep only clear, reusable clothing images.
- Save final candidates instead of every experiment.
- Use [History](/dashboard/history) to revisit generated outputs.
- Use 360° video only for looks that are ready for deeper review.
